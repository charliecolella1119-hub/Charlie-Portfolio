Project Case Study

Molecular Dynamics Simulator

Scientific Model

The desktop simulator supports atomic Lennard-Jones particles, directional coarse-grained water, and a TIP3P-inspired three-site model with oxygen Lennard-Jones interactions and partial charges. Periodic boundaries make the box behave like a repeating sample.

Numerical Method

Velocity Verlet advances the system in time. NVT experiments use a weak Berendsen thermostat to approach a Kelvin-labeled target; switching to NVE removes that coupling so energy can exchange naturally between kinetic and potential forms.

Analysis Tools

Live tools compare particle speeds with a Maxwell-Boltzmann curve, compute the radial distribution function, track temperature and pressure, and export thermodynamic time series. Regression tests check force gradients, preset temperatures, and thermostat behavior.
